## Purpose
The purpose of this capability is to enhance the visibility of archived specifications. By applying visual highlighting and formatting, users can easily distinguish archived specs from living ones.

## ADDED Requirements

### Requirement: Highlight Archived Specs
- **MUST** visually highlight archived specifications in the same manner as living specs.

#### Scenario: Display Highlighted Archived Specs
- **WHEN** a user views archived specifications
- **THEN** the archived specs shall be visually highlighted and formatted.

#### Scenario: Consistent Formatting
- **WHEN** archived specs are displayed
- **THEN** the formatting shall be consistent with the highlighting of living specs.

#### Scenario: User Interaction
- **WHEN** a user hovers over an archived spec
- **THEN** additional information about the spec shall be displayed.

#### Scenario: Accessibility Compliance
- **WHEN** archived specs are highlighted
- **THEN** the highlighting must comply with accessibility standards for color contrast.
